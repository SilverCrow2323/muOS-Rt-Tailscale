# First connection

The first login uses a QR code generated by the app. Scan it with a phone that is already signed in to the Tailscale account you want to use.

## Connect

1. Launch **Applications → Tailscale**.
2. Open **Status → Log in**.
3. Wait for the QR code to appear.
4. Scan it with your phone and approve the device in your Tailscale account.
5. Return to the handheld and wait for the status to update.

## Start at boot

1. Open **Settings → Start at boot**.
2. Switch it on.
3. The app creates its muOS user init script and enables **Advanced settings → User Init Scripts** when required.
4. Run **System → Run diagnostics** if the service does not start after reboot.

> **Optional** — Use an exit node from the Devices/Peers screen after the device has connected. Availability depends on the other node's Tailscale configuration.

## Verify

- The Status tab shows the device connected.
- The Devices/Peers list shows other devices in the tailnet.
- **System → Run diagnostics** reports the service and panel state.

See [Troubleshooting](Troubleshooting) if login waits indefinitely.
