# Controls

Rt:Tailscale-M is designed for the handheld D-pad. The on-screen legend uses button artwork rather than a text-only key list.

## Main controls

- D-pad moves between rows, tabs and devices.
- Confirm opens the selected item or activates the highlighted action.
- Back returns to the previous view.
- Shoulder buttons move between tabs where shown.
- **SELECT + START** quits the application.

## Button layout

The default artwork follows the Nintendo layout used by Anbernic handhelds: **A is the right face button and B is the bottom face button**.

> [!IMPORTANT]
> **MUST KNOW!!** If the physical A/B positions feel reversed, open **Settings → Nintendo button layout** and switch the layout. Do not assume another controller uses the same physical arrangement.

## Keyboard testing on PC

- Arrow keys: navigate.
- Enter: A / confirm.
- Escape: B / back.
- X and Y: face-button actions.
- Q / E: shoulder actions.
- Ctrl + Q: quit.
